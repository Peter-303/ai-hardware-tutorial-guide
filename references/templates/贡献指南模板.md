# 🤝 参与贡献

首先，谢谢你看完教程还愿意点进这个页面——愿意回馈社区的人，是这个项目最宝贵的财富 ❤️

无论你是什么背景，总有一种方式适合你：

---

## 🐛 Level 1：发现错误，告诉我们（1 分钟）

教程里有错字、过期的链接、跑不通的步骤？

👉 [提一个 issue](../../issues/new?template=bug)，标题写清章节位置，比如"第 2 章 3.1 节：截图与实际界面不符"。

> 你的每一次纠错，都会让后面几百个学习者少卡一次。

## 💡 Level 2：许愿新内容（2 分钟）

想让教程覆盖某个主题？比如"如何给小车加摄像头"？

👉 [提一个许愿 issue](../../issues/new?template=wish)，说清楚你想学什么、卡在哪。被采纳的需求会进入项目 Roadmap。

## ✍️ Level 3：提交内容 PR（从一段话到一篇番外）

欢迎这些类型的 PR：

| 类型 | 说明 | 积分 |
|---|---|---|
| 纠错修订 | 错字、过期信息、失效链接修复 | +1 |
| 内容增强 | 补充常见报错、优化配图说明、完善 FAQ | +2 |
| 番外篇 | 你的二次开发教程（放进 `Extra/` 目录），如"给小车装上机械臂" | +3 |
| 章节级贡献 | 认领大纲中 ⬜ 状态的章节 | +5 |

**PR 前请确认：**

- [ ] 文字符合《[语言与风格指南](../02-语言与风格指南.md)》（亲切、不劝退、步骤三件套齐全）
- [ ] 涉及操作的步骤：配图 + 预期结果 + 卡住兜底
- [ ] 代码可运行，标注了依赖版本号
- [ ] PR 描述里写清"改了什么、为什么改"

审核节奏：我们会尽量在 **7 天内**回复每一个 PR。审核通过后，根据内容类型分级合并。

## 🛟 Level 4：成为助教/核心贡献者

- **助教**：带过一期组队学习答疑，是最快了解项目的方式。在组队学习群内报名即可。
- **核心贡献者**：持续贡献 3 个版本周期以上，会被邀请进入核心组，参与教程方向决策。

---

## 🏅 你的贡献会被看见

- 所有贡献者都会进入 README **致谢名单**（实名 + 角色标签，按贡献排序）
- 积分可兑换项目周边（贴纸/徽章/定制零件）
- 季度"最佳贡献者"会在公众号和社群实名感谢

## 📜 行为准则

- 对新手友善：没有"愚蠢的问题"，只有我们没写清楚的教程
- 就事论事：讨论技术方案时，对事不对人
- 诚信红线：不抄袭、不搬运他人内容冒充原创

期待与你一起，让更多人造出属于自己的【成品名】！🚀
